# Lumivara Online Client

ไคลเอนต์สำหรับเล่น Lumivara Online บน Android ใช้ Android System WebView พร้อมโหมดเต็มจอ หน้าต่างเกมขนาดเล็ก และเมนูภาษาไทย/อังกฤษ

## ดาวน์โหลด

ดาวน์โหลด APK ได้ที่หน้า [Releases](https://github.com/newkiss2582/Lumivara-Online-Client/releases)

สำหรับ Android รุ่น 1.9 เลือกไฟล์ **Lumivara-Online-Android-1.9.apk**

รองรับ Android 8.0 ขึ้นไป ขนาดไฟล์ประมาณ 13.8 MB

## ความสามารถ

- เล่นเกมเต็มจอแนวนอน
- เปิดเกมเป็นหน้าต่างขนาดเล็ก พร้อมลากย้ายและปรับขนาด
- ย่อหน้าต่างเป็นปุ่มลอย แล้วกดกลับเข้าเกม
- เลือกภาษาเมนูแอป: ไทย / English / ตามภาษาเครื่อง
- ดูคลิปสอนติดตั้งและตั้งค่าจากในแอป โดยไม่ใช้เน็ต

## วิธีติดตั้ง

1. ดาวน์โหลด APK จากหน้า Releases
2. เปิดไฟล์และอนุญาตการติดตั้งจากแหล่งนี้ หากระบบร้องขอ
3. เปิดแอป Lumivara Online
4. อนุญาตการแสดงทับแอปอื่นเพื่อใช้หน้าต่างลอย
5. ตั้งค่าการแจ้งเตือนและแบตเตอรี่ตามคำแนะนำในแอป
6. เลือกเปิดเกมเต็มจอ หน้าต่างขนาดเล็ก หรือปุ่มลอย

หากใช้รุ่น WebView เดิม ให้ติดตั้งทับโดยไม่ถอนการติดตั้ง เพื่อเก็บข้อมูลเกมและบัญชี Guest เดิม

## คลิปสอนติดตั้ง

เปิดหน้าตั้งค่า → **▶ คลิปสอนติดตั้งและตั้งค่า**

คลิปภาษาไทยยาวประมาณ 47 วินาที รวมอยู่ใน APK แตะวิดีโอเพื่อแสดงปุ่มเล่น/หยุดและแถบเลื่อนเวลา หรือกด **เล่นซ้ำ** เพื่อเริ่มใหม่

คลิปแสดงหน้าตาเมนูจากรุ่นก่อน บางส่วนอาจต่างจากรุ่นปัจจุบันหรือเครื่องที่ใช้งาน

## ภาษาเมนูแอป

เปิดหน้าตั้งค่า → **ภาษาแอป / App language**

เลือกได้ทั้งภาษาไทย English และตามภาษาเครื่อง แอปจดจำตัวเลือกไว้ โดยภาษาในเกมตั้งค่าแยกจากเมนูแอป

## หมายเหตุ

- ต้องใช้อินเทอร์เน็ตในการเล่นเกม
- Android อาจจำกัดการทำงานเบื้องหลังตามการตั้งค่าและรุ่นของเครื่อง
- Google Login ยังอยู่ระหว่างการทดลอง
- APK รุ่นนี้ไม่ได้อัปเดตแอป Gecko Test
- ตรวจสอบ build และลายเซ็นแล้ว ยังไม่ได้ทดสอบ APK รุ่น 1.9 บนมือถือจริง
