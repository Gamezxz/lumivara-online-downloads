# Lumivara Online Client

ไคลเอนต์สำหรับเล่น Lumivara Online บน Android ใช้ Android System WebView พร้อมโหมดเต็มจอและหน้าต่างเกมขนาดเล็ก

## ดาวน์โหลด

ดาวน์โหลดไฟล์ APK จากหน้า [Releases](https://github.com/newkiss2582/Lumivara-Online-Client/releases)

สำหรับ Android รุ่น 1.8 เลือกไฟล์ `Lumivara-Online-Android-1.8.apk`

## ความสามารถ

- เล่นเกมเต็มจอแนวนอน
- เปิดเกมเป็นหน้าต่างขนาดเล็ก พร้อมลากย้ายและปรับขนาด
- ย่อหน้าต่างเป็นปุ่มลอย แล้วกดกลับเข้าเกม
- เลือกภาษาเมนูแอปได้: ไทย / English / ตามภาษาเครื่อง
- จดจำภาษาเมนูที่เลือก โดยภาษาในเกมตั้งค่าแยกต่างหาก

## การติดตั้ง

1. ดาวน์โหลด APK จากหน้า Releases
2. เปิดไฟล์และอนุญาตการติดตั้งจากแหล่งนี้ หากระบบร้องขอ
3. เปิดแอป แล้วตั้งค่าสิทธิ์แสดงทับแอปอื่นเพื่อใช้หน้าต่างลอย
4. ตั้งค่าการใช้แบตเตอรี่ตามคำแนะนำในแอป

รองรับ Android 8.0 ขึ้นไป

ผู้ใช้รุ่น WebView เดิมสามารถติดตั้งทับได้ โดยไม่ต้องถอนการติดตั้ง เพื่อเก็บข้อมูลเกมและบัญชี Guest เดิม

## หมายเหตุ

- Android อาจจำกัดการทำงานเบื้องหลังตามการตั้งค่าและรุ่นของเครื่อง
- Google Login ยังอยู่ระหว่างการทดลอง
- APK รุ่นนี้เป็นรุ่น WebView และไม่ได้อัปเดตแอป Gecko Test
